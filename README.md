# codespace-dotfiles

Try to stay as much in the defaults as possible, but this is a few settings to change configs for new Codespaces and devcontainers.
* Fixes for history (always flush so it's not lost)
* A few git config options
* A few aliast
* A few custom Copilot instructions (these have expanded and probably deserves to be their own repo at this point, but I already have this wired in and working)
